# 📚 Mi Biblioteca

Sistema de biblioteca: libros, socios y préstamos con control de devoluciones y vencimientos. HTML + CSS + JavaScript puro, sin dependencias. Los datos se guardan en el `localStorage` del navegador.

## Estructura

```
biblioteca-app/
├── index.html
├── css/styles.css
├── js/storage.js   (acceso a localStorage)
├── js/app.js       (lógica e interfaz)
└── README.md
```

## Publicar en GitHub Pages

1. Crea un repo (por ejemplo `sistema-biblioteca`).
2. Sube **el contenido** de esta carpeta a la raíz (arrastrando `index.html`, `css` y `js`).
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
